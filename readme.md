# Agréments : a tool to centralize RBAC and Auth

| This Go application objectives are : |  Status |
|---|---|
| - Centralize management of projects-users-rbac of others tools<br> - Single Sign On (SSO) server, client, based on Openid Connect,<br> - Use and fill Openldap as annuary for all tools and sso<br> - Automate transfert of some users,groups from your annuary to Ldap<br> - Read RBAC from .csv files ; it can be generated by excel/calc tool script &nbsp; &nbsp; &nbsp;<br> - or Read RBAC from markdown file, one by project, inside source code<br> - or Edit RBAC from the Web UI, with Projects Portfolio | ![wip](./resources/img/work-in-progress.png) | 

> RBAC = Role Base Access Control : Set of Associations ( User-Project-Role )
